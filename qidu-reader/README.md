# 栖读 0.7 · 安卓 / iOS 阅读器原型

基于 React Native + Expo 的共享源码，参考栖阅的简洁阅读体验，按开源阅读 JSON 字段实现部分书源适配。独立编写，未复制栖阅素材或 Legado 源码；当前不是 Legado 完整移植版。

## 已实现的源码功能

- 书架、UTF-8 TXT 导入、中文章节切分、章节切换与阅读位置保存。
- 四种背景颜色、本地 PNG/JPG/WebP 背景图、系统字体和本地 TTF/OTF 字体导入、字号与行距。
- JSON 书源链接、文件或粘贴导入、去重、删除、选择、关键词搜索、目录获取、正文获取及已读章节缓存。链接导入包含超时、HTTP、网页响应和格式错误提示。
- 按用户要求改为液态玻璃风格：透光卡片、原生或回退模糊、高光边缘、分组筛选与带弹簧动画的悬浮导航。详见《液态玻璃说明.md》。应用背景和阅读背景可分别换图。
- 本机存储；长按书籍移除。图片和字体复制到应用目录。
- 章节书签及独立书签页；系统 TTS 分段朗读当前章，可调语速，换章和离开阅读器时停止。
- 实际前台阅读 / 听书统计，今日合计、近 7 / 30 日图表、连续阅读天数。午夜按本地日期拆分，后台暂停计时。
- 手动预缓存最近阅读的网络书籍后续 5 / 10 / 50 章；清理缓存时保留当前章和本地 TXT。
- 备份 JSON 文件分享及恢复；恢复前确认替换。备份含书架、书源、统计、设置，不包含图片、字体文件或安全存储里的登录会话。

## 发现推荐

发现首页现在直接展示两张精选书卡，以及推荐榜、完本榜、新书榜的横向书架；点击查看全部可分页展开。点击大灰狼书源卡片直接进入推荐，长按可搜索与管理。平台和频道筛选收进顶部菜单，单个榜单失败时可单独重试。实际接口验证：181 个分类、21 本推荐书及首本 447 章目录。当前按书源内置发现页适配；其他发布网站需单独提供网址。书签入口移到设置页。详见《发现推荐与未签名IPA.md》。

## 书源兼容范围

支持字段：`bookSourceName`、`bookSourceUrl`、`searchUrl`、`header`、`ruleSearch`、`ruleBookInfo.tocUrl`、`ruleToc`、`ruleContent.content`。

支持 GET 搜索、`{{key}}` / `{{page}}` 搜索地址变量、标准 CSS 选择器（例如 `.books .book`、`h2@text`、`a@href`）、基础阅读选择器（`class.book`、`id.content`、`tag.a.0@href`，可用 `@` 串联）、基础 JSONPath（例如 `$.books[*]`、`$.name`）。CSS 无提取后缀时取文本。JSON 列表可使用数组路径或 `[*]`。

大灰狼 5.9.30 VIP 完全版已加入专用小说适配，包括应用内账号登录、线路与平台选择、搜索、目录和正文请求。账号会话保存在 SecureStore，不进入普通书架或备份。已实际验证公开搜索和目录；真实付费会话及正文仍待真机验证。详见《大灰狼兼容记录.md》。

**通用解析器尚未实现**：任意 JS / `java.*` 桥接、XPath、复杂专用选择器、组合/替换规则、POST 搜索、通用登录与 Cookie 管理、验证码、GBK 解码、分页目录/正文、自动换源、EPUB/PDF、云同步。大灰狼专用适配不代表上述通用能力已实现。

## 启动与构建

安装 Node.js LTS，然后在本目录执行：

```powershell
npm install
npx expo install --fix
npm test
npx expo start
```

安卓和苹果可用相应版本 Expo Go 扫码开发预览。若 Expo Go 已不支持 SDK 54，请先按 Expo 官方迁移指南升级 SDK，或构建 development client。当前依赖以 SDK 54 为目标，`expo install --fix` 用于校准原生模块版本。

安卓开发构建需要 Android SDK：`npm run android`。iOS 本地构建需要 macOS + Xcode：`npm run ios`。云端打包可用 EAS：

```powershell
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform ios --profile preview
```

正式签名、设备配置、商店提交需要相应开发者账号。iOS 的任意网络书源若使用 HTTP，将受系统网络安全策略限制，当前以 HTTPS 为默认。
