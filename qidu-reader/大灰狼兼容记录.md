## 已实现

针对这个固定版本直接适配其小说 HTTP 协议：

| 功能 | 实现 |
| --- | --- |
| 线路选择 | 静态提取原书源 host 数组，只提供其中的 HTTPS 线路 |
| 账号登录 | 应用内邮箱 / 密码表单，调用所选线路的 /login_api |
| 本机会话 | Expo SecureStore，密码不持久化，会话不进入普通书架文件及备份 |
| 设备标识 | 安卓 Android ID / iOS vendor ID；不可用时使用安全存储中的安装 UUID |
| 搜索 | /search，支持来源平台配置，当前界面展示第 1 页 |
| 目录 | /catalog，按服务响应映射章节，过滤卷标题 |
| 正文 | /content，携带本机授权会话，取文字并保留基本段落 |
| 会话限制 | 会话绑定当前线路，不自动向其他域名转发，切换线路后重新登录 |
| 服务错误 | 登录失败、权限拒绝、空正文、非 JSON 响应、网络错误、超时均明确报错 |

服务允许时搜索和目录可匿名浏览。付费正文请求要求当前线路有登录会话，服务端继续决定账号能否访问内容。没有实现绕过账号权限、设备限制或付费校验。

## 使用流程

1. 运行或构建应用，在“书源”页点击“＋”。
2. 下载地址已预填，点击“从链接导入”。
3. 点击大灰狼卡片，在“账号与线路”选择 HTTPS 服务器。
4. 在应用中自行填写邮箱和密码、登录，不要将密码或 Cookie 发到聊天中。
5. 按需要设置来源平台，搜索书籍，再加入书架阅读。
