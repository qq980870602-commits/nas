# 栖读 0.4 液态玻璃界面

已调整书架卡片、书源网格、搜索框、设置分组、账号表单、阅读按钮与工具栏、设置弹层及底部导航。

- 采用透光材质、白色边缘高光、柔和投影及薄荷 / 冰蓝背景。
- 支持的 iOS 26 使用 `expo-glass-effect` 原生材质，并检查系统 API 与效果可用性。
- 较旧 iOS 使用 `expo-blur`。安卓的导航和工具栏使用 BlurView 实验性模糊；列表卡片使用透光色层及高光，避免每个列表项重复实时模糊。
- 底栏选中背景通过弹簧动画移动，卡片和按钮带轻微按压反馈。
- 系统开启“降低透明度”时使用不透明底色，开启“减少动态效果”时关闭按压及底栏弹簧动画。
- 阅读正文继续使用用户选择的背景及字体，玻璃效果只用于控制界面。

已有 18 项业务测试通过。网页预览在 390×844 尺寸检查了书架、搜索过滤和设置页，未发现浏览器错误；修正了玻璃层遮挡搜索文字的问题。

截图使用 `DesignPreview.jsx` 的示例书架，是网页回退效果，不能代替 iOS 原生折射、安卓性能或真机触控验证。原生 IPA / APK 仍未生成。

## 开发预览

普通运行使用真实 App：`npx expo start`。

网页设计预览只在显式设置环境变量时启用，PowerShell 命令：

```powershell
$env:EXPO_PUBLIC_UI_PREVIEW = '1'
npx expo start --web
```

导出或构建正式版本前移除该变量。安卓和 iOS 入口始终运行真实 App。

组件参考：[Expo GlassEffect](https://docs.expo.dev/versions/latest/sdk/glass-effect/)、[Expo BlurView](https://docs.expo.dev/versions/latest/sdk/blur-view/)。SDK 54 使用的具体 API 以安装包本地类型定义为准。
