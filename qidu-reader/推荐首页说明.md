# 0.6 推荐首页

按用户最新截图调整：点击大灰狼书源卡片，直接进入带书籍封面的推荐首页。

- 顶部为紧凑的线路 / 账号、平台 / 频道及分类菜单。
- 页面先显示两张精选书卡，下方自动加载推荐榜、完本榜、新书榜横向书架。
- 点击书籍查看简介并加入书架，点击查看全部展开分页榜单。
- 三个榜单分别加载，单个失败可单独重试；缺失的榜单不伪造入口。
- 保留液态玻璃外观、背景图片和字体设置。搜索 / 登录 / 管理可长按书源或从推荐页顶部进入。

本地测试 21 项通过，新增首页榜单优先级和缺失入口处理验证。网页预览检查了源卡片直达首页及查看全部入口，没有浏览器错误；截图是明确标注的示例数据。安卓 / iOS JavaScript 打包检查与原生 IPA 构建是不同验证步骤，尚无原生安装包。
